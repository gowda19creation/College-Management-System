# 🎓 College Management System

A desktop application developed using **C# Windows Forms** and **SQL Server** to manage college operations such as students, teachers, courses, and fees.

## ✨ Features
- Student Management
- Teacher Management
- Course Management
- Fee Management
- Login System
- Search and Update Records
- SQL Server Database Integration

## 🛠 Technologies Used
- C#
- Windows Forms
- SQL Server
- ADO.NET
- Visual Studio

## 🚀 How to Run
1. Download or clone this repository.
2. Open `CollegeManagementSystem.sln` in Visual Studio.
3. Restore the SQL Server database.
4. Update the connection string if required.
5. Build and run the project.
